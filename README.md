# Pokemon-stuff

Eigene Web-Tools rund um Pokémon-Karten. Jede App liegt in einem eigenen Ordner und läuft ohne Server direkt im Browser.

Übersicht aller Apps: **https://jojo-1811.github.io/Pokemon-stuff/**

| App | Ordner | Link |
|---|---|---|
| Kartenzentrierung – misst das Centering aus einem Foto | [`kartenzentrierung/`](kartenzentrierung/) | [öffnen](https://jojo-1811.github.io/Pokemon-stuff/kartenzentrierung/) |
| Preisabfrage - macht Kartenfinden auf Cardmarket einfacher | [`preisfindung/`] (preisfindung/) |[öffnen](https://jojo-1811.github.io/Pokemon-stuff/preisfindung/) |

## Neue App hinzufügen

1. Neuen Ordner anlegen, z. B. `meine-app/`, mit einer eigenen `index.html` darin.
2. In der `index.html` im Hauptordner einen weiteren Eintrag in der Liste ergänzen (Vorlage steht als Kommentar im Code).
3. Die App ist dann unter `https://jojo-1811.github.io/Pokemon-stuff/meine-app/` erreichbar.
